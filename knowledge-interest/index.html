MODULE 01

一、摆脱“负利息”的困扰

经验为什么有时会越积越值钱，有时却会拖住一个策划？

学习目标：识别经验中的正资产与负资产，避免在错误概念上继续堆积。

核心观点

  • 入行早、资历深、经历项目多，不自动等于优秀策划。
  • 只围绕自己负责的模块积累，可能形成路径依赖，经验反而变成“负资产”。
  • 知识体系建立在已有概念之上；概念模糊，后续学习和决策都会一起偏移。

原文里的典型误区

只关注养成系统，却忽视战斗系统和社交需求的关联；或者用打折、充返等熟悉手段，直接去挽救 ARPU。问题不一定是动作不够快，而可能是对问题的定义本身就错了。

MODULE 02

二、复利的基石

为什么策划团队容易“鸡同鸭讲”？

学习目标：理解清晰概念、统一标准和共同语言，是知识能够产生复利的前提。

核心观点

  • 同一个词在不同团队里可能有不同名称和理解；名称相同，也不代表概念相同。
  • “竞品”“横向卡牌”“纵向养成”等词，只有定义清楚、边界明确，才有设计价值。
  • 能把复杂专业的东西用简单、少歧义的语言说清楚，是策划的重要能力。

把术语变成可工作的定义

讨论“竞品”时，先说清楚比较的是目标用户、玩法结构，还是系统框架；讨论“横向/纵向”时，说明它究竟改变的是数值追求、角色收集、搭配策略，还是其他体验。

MODULE 03

三、策划的核心能力

技能能力和认知能力，分别解决什么问题？

学习目标：区分“把事情做出来”的技能，和“判断该做什么”的认知。

核心观点

  • 技能能力包括代码、美术、文档、工具链、关卡引擎等，有较明确的训练和衡量方式。
  • 技能让策划更理解实现逻辑、减少错误，但技术能力本身并不会自动带来好的设计。
  • 认知能力包括思维、理解、判断、洞察和创造力，决定能否看见用户需求与全局框架。

从执行者到决策者

同样一份用户反馈，不同的人可能得出不同结论。认知能力强的策划，会继续追问现象背后的原因、系统之间的关系，以及什么才是更好的方案。

MODULE 04

四、科学的验证迭代

如何避免把一次成功误认为一套方法？

学习目标：建立从假设到方法论的验证路径，并认识游戏行业的因果不确定性。

核心观点

  • 完整路径是：提出假设 → 设定目标 → 验证结果 → 反复实验 → 提炼方法论。
  • 游戏是混沌系统，表现会同时受到 bug、美术、玩法、易用性、IP、商业化等因素影响。
  • 盲目套用历史成功经验、只看成功数据、回避证伪，都会制造虚假的确定感。

把“我觉得会更好”改成可验证假设

不要只写“这个礼包会提升付费”。应写成：对某类用户，在某个触发时机提供某种礼包，预期改变哪项行为；上线后用什么指标、对照什么基线，判断假设是否成立。

MODULE 05

五、贝叶斯定理

新信息来了，我应该坚持原判断，还是更新判断？

学习目标：用先验、证据和后验理解“开放心态”，让判断随着信息变化而校准。

核心观点

P(A｜B) = P(B｜A) × P(A) / P(B)
  • P(A) 是看到新证据前，对假设 A 的原先判断，也就是先验。
  • P(B｜A) 是假设 A 成立时，看到证据 B 的可能性；P(B) 是证据本身出现的概率。
  • P(A｜B) 是看到证据 B 后，对假设 A 的更新判断，也就是后验。

策划如何使用贝叶斯思维

玩家反馈、数据波动和一次测试结果都是证据，不是自动成立的结论。先问：我原来相信什么？这条证据在不同原因下是否同样常见？再决定应该把判断调高、调低，还是暂时保持不确定。

MODULE 06

六、思维能力的迁移

怎样从一个模块的熟练，走向全局策划？

学习目标：把局部经验迁移到相邻系统，逐步形成全局框架和战略视角。

核心观点

  • 常见路径是：小功能 → 中型系统 → 玩法模块 → 核心玩法 → 全局规划。
  • 成长通常经历：单点突破（细节到框架）→ 全局视角（框架到战略）→ 知识与经验叠加。
  • 每一次学习和实践，都应该成为下一次突破可以调用的“复利资产”。

A 同学的能力迁移

从角色设计出发，进入战斗验证，再负责玩法投放与全局规划，最后扩展到商业化和数值调优。关键不是岗位名称变化，而是逐步理解角色、战斗、内容投放和商业结果之间的关联。

MODULE 07

七、超越环境的成长

项目环境有限时，怎样继续提升认知？

学习目标：把成长从单一项目中拆出来，建立分析、记录、模型和交流的个人系统。

核心观点

  • 环境会限制成长，也可能奖励短期有效但长期错误的做法；不能把偶然有效当成正确方法。
  • 选择 1—3 款相关产品，持续做竞品分析、个人体验和工作记录。
  • 建立模型、预测变化、对比实际结果，再通过复盘和跨界交流修正认知。

短期 KPI 与长期判断

一个打折礼包可能暂时修复数据，但如果每次问题都只用打折解决，就会把偶然有效固化成错误习惯。真正的成长，是记录当时为什么这样做、结果是什么、代价是什么。

MODULE 08

八、好饭不怕晚

知识的“利率”由谁决定？

学习目标：把成长理解为概念校准与验证效率共同作用的长期复利。

核心观点

  • 知识的利率 = 概念校准 × 验证效率。底层概念错了，时间越长，错误可能越大。
  • 比起“早”，更重要的是“对”：正确的开始，比过早的开始更重要。
  • 未来的你，是今天持续选择、记录、验证和修正的复利结果。

把成长变成一个可执行的循环

每天不只是完成任务，还要留下一个被校准的概念、一个被验证的假设，或一条能帮助下一次决策的记录。积累不是耗时间，而是优化时间。
